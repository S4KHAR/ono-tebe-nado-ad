# Оно тебе надо

Учебный проект второго спринта курса по фронтенд-разработке Яндекс Практикума.

Одностраничный сайт аукциона вещей, в которые никто не верил. На странице представлены лоты, информация об аукционе и контакты.

## Технологии

- HTML5 и семантическая разметка.
- CSS3.
- Flexbox и Grid Layout.
- Методология БЭМ.

## Запуск

Скачайте репозиторий и откройте файл index.html в браузере.
